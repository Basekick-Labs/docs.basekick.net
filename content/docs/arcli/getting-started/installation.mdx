---

arcli ships for Linux, macOS, and Windows on AMD64 and ARM64. The latest release is <LatestVersion repo="Basekick-Labs/arcli" />.

## Homebrew

```bash
brew install basekick-labs/tap/arcli
arcli --version
```

The formula installs the binary, shell completion, and man pages.

## Linux packages

Release tags use `26.09.4`; Linux package filenames use `26.9.4`.

```bash
V=26.09.4
PKG=26.9.4
BASE=https://github.com/Basekick-Labs/arcli/releases/download/v$V
```

<Tabs items={['Debian / Ubuntu', 'RHEL / Fedora / Rocky', 'Arch']}>
  <Tab value="Debian / Ubuntu">

```bash
curl -LO $BASE/arcli_${PKG}_amd64.deb
sudo dpkg -i arcli_${PKG}_amd64.deb
```

Use `_arm64.deb` on ARM64.

  </Tab>
  <Tab value="RHEL / Fedora / Rocky">

```bash
sudo rpm --import https://github.com/basekick-labs/arc/releases/latest/download/RPM-GPG-KEY-basekick
curl -LO $BASE/arcli-${PKG}-1.x86_64.rpm
sudo dnf install -y ./arcli-${PKG}-1.x86_64.rpm
```

Use `.aarch64.rpm` on ARM64. To upgrade, use `sudo dnf upgrade -y ./arcli-${PKG}-1.x86_64.rpm`.

arcli RPMs up to 26.09.4 are unsigned; future releases will be signed with the Basekick Labs package key, the same key as Arc's, which the `rpm --import` line installs. `dnf install ./arcli-<version>-1.x86_64.rpm` installs a signed or an unsigned package; `rpm -i` refuses an unsigned package where rpm enforces signatures, as rpm 6.1 on Fedora 45 does.

  </Tab>
  <Tab value="Arch">

```bash
curl -LO $BASE/arcli-${PKG}-1-x86_64.pkg.tar.zst
sudo pacman -U arcli-${PKG}-1-x86_64.pkg.tar.zst
```

Use `-aarch64.pkg.tar.zst` on ARM64.

  </Tab>
</Tabs>

## Docker

```bash
docker run --rm \
  -e ARC_ENDPOINT=http://arc.internal:8000 \
  -e ARC_TOKEN=YOUR-TOKEN \
  ghcr.io/basekick-labs/arcli:26.09.4 ping
```

Use `latest` to track the newest final release.

## Release archives

Download the archive for your platform from [GitHub Releases](https://github.com/Basekick-Labs/arcli/releases). For Linux AMD64:

```bash
curl -LO https://github.com/Basekick-Labs/arcli/releases/download/v26.09.4/arcli_26.09.4_linux_amd64.tar.gz
tar xzf arcli_26.09.4_linux_amd64.tar.gz
sudo install arcli /usr/local/bin/
```

Archives include shell completion and man pages. Releases also publish signed checksums and SPDX SBOMs.

## From source

```bash
go install github.com/basekick-labs/arcli/cmd/arcli@latest
```

This builds the current `main` branch. Use one of the release channels above when you need a pinned version.
