---
title: "Installation"
description: "Install Arc with Docker, a native Linux package, the Kubernetes Helm chart, or the AWS Marketplace AMI, and pick the path that matches your deployment."
---

Arc ships as a single Go binary, so every install path below gets you the same server. Pick the one that matches where you are running it.

- **[Docker](/arc/installation/docker/)** — Run the published image with a data volume — the fastest way to a working instance.
- **[Native packages](/arc/installation/native/)** — .deb, .rpm, and Arch packages with a systemd service, or a build from source.
- **[Kubernetes](/arc/installation/kubernetes/)** — Deploy with the Helm chart, including storage credentials and persistent volumes.
- **[AWS Marketplace](/arc/installation/aws-marketplace/)** — Launch the pre-built AMI with S3 storage already wired up.
