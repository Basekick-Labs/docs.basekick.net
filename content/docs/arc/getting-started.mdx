Get Arc running and query real data in a few minutes.

## 1. Start Arc

<Tabs items={['Docker', 'Kubernetes', 'Debian / Ubuntu', 'RHEL / Fedora']}>
  <Tab value="Docker">

```bash
docker run -d \
  --name arc \
  -p 8000:8000 \
  -v arc-data:/app/data \
  ghcr.io/basekick-labs/arc:latest
```

  </Tab>
  <Tab value="Kubernetes">

```bash
LATEST=$(curl -s https://api.github.com/repos/basekick-labs/arc/releases/latest | grep tag_name | cut -d '"' -f 4 | sed 's/v//')
helm install arc https://github.com/basekick-labs/arc/releases/download/v${LATEST}/arc-${LATEST}.tgz
kubectl port-forward svc/arc 8000:8000
```

  </Tab>
  <Tab value="Debian / Ubuntu">

```bash
LATEST=$(curl -s https://api.github.com/repos/basekick-labs/arc/releases/latest | grep tag_name | cut -d '"' -f 4 | sed 's/v//')
curl -LO https://github.com/basekick-labs/arc/releases/download/v${LATEST}/arc_${LATEST}_amd64.deb
sudo dpkg -i arc_${LATEST}_amd64.deb
sudo systemctl enable --now arc
```

  </Tab>
  <Tab value="RHEL / Fedora">

```bash
LATEST=$(curl -s https://api.github.com/repos/basekick-labs/arc/releases/latest | grep tag_name | cut -d '"' -f 4 | sed 's/v//')
curl -LO https://github.com/basekick-labs/arc/releases/download/v${LATEST}/arc-${LATEST}-1.x86_64.rpm
sudo rpm -i arc-${LATEST}-1.x86_64.rpm
sudo systemctl enable --now arc
```

  </Tab>
</Tabs>

Confirm that Arc is ready:

```bash
curl http://localhost:8000/health
```

See [Installation](/arc/installation/) for storage, networking, other architectures, and production configuration.

## 2. Get the admin token

Arc prints an admin token the first time it starts.

<Tabs items={['Docker', 'Kubernetes', 'Native']}>
  <Tab value="Docker">

```bash
docker logs arc 2>&1 | grep -i "admin"
```

  </Tab>
  <Tab value="Kubernetes">

```bash
kubectl logs -l app=arc | grep -i "admin"
```

  </Tab>
  <Tab value="Native">

```bash
sudo journalctl -u arc | grep -i "admin"
```

  </Tab>
</Tabs>

Copy the value that begins with `arc_`:

```bash
export ARC_TOKEN="arc_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

## 3. Connect with arcli

Install [arcli](/arcli/), save the Arc endpoint, and verify the connection:

```bash
brew install basekick-labs/tap/arcli
arcli config create --name local --endpoint http://localhost:8000 --token "$ARC_TOKEN"
arcli ping
```

See [Install arcli](/arcli/getting-started/installation/) for Docker, Linux packages, and downloadable archives.

## 4. Load and query real data

Load a month of NYC Citi Bike trips:

```bash
arcli sample load citibike
```

arcli verifies and imports about one million rows, then prints useful queries. Try the busiest-stations query:

```bash
arcli query --database nyc "SELECT start_station_name AS station, count(*) AS trips FROM citibike_trips GROUP BY 1 ORDER BY trips DESC LIMIT 5"
```

## Write your own data

```bash
arcli db create metrics
echo "cpu,host=server01 usage=95.0" | arcli write --database metrics
arcli query --database metrics "SELECT * FROM cpu"
```

Arc buffers new writes briefly. If the first query is empty, run it again after a few seconds.
